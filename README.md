## 🩺 Project Overview

This project analyzes healthcare patient records using **Python and Exploratory Data Analysis (EDA)** techniques.

The analysis focuses on understanding patient demographics, medical conditions, billing patterns, admission types, medications, test results, hospital records, and relationships between key variables.

### 🎯 Objective

The main objective of this project is to explore healthcare data, identify meaningful patterns, and communicate data-driven observations through analysis and visualization.

## 🧹 Data Cleaning

The dataset initially contained **55,500 records**.

The following data-cleaning steps were performed:

- 🔍 Checked the dataset structure and data types
- 🔍 Checked for missing values
- 🔍 Identified duplicate records
- 🗑️ Removed **534 duplicate records**
- ✅ Final dataset contained **54,966 records**

## 💡 Key Findings

📌 **55,500** records were present in the original dataset.

🗑️ **534 duplicate records** were identified and removed.

✅ The final dataset contained **54,966 records**.

🎂 Patient ages ranged from **13 to 89 years**, with an average age of approximately **51.5 years**.

👥 Male and female patient records were almost evenly distributed.

🏥 The six medical conditions were relatively evenly represented.

💰 Average billing amounts were relatively similar across the six medical conditions.

🚑 Elective, Urgent, and Emergency admissions were relatively evenly distributed.

💊 Medication categories showed relatively similar record counts.

🧪 Normal, Abnormal, and Inconclusive test results had relatively similar distributions.

🔗 Age, Billing Amount, and Room Number showed very weak linear correlations.
